# Quality-at-a-Discount

One screening playbook for **long-term accumulation** (tích sản).

Core, unchanged across markets:

1. The business is high quality and hard to replace.
2. The price is a **true sale-off**, not a dip.
3. Hold for years. Valid output is **zero names**.

Markets are a variable: **VN · US · UK · DE · AU**. The same file auto-routes from the question (tickers, exchanges, language). AI/semiconductor names must pass a cycle overlay before valuation. If nothing clears, fall back to cash or a real-asset sleeve (gold, silver, metals, fertilizer, oil) — not to a stretched equity.
